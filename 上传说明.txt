把 nestlink-oss 文件夹里的 5 个文件/文件夹拖到 GitHub 网页的上传区
============================================================

你新建的仓库页面打开着，按下面做：

第 1 步  在仓库首页点「uploading an existing file」链接
        （或地址栏直接进：https://github.com/你的用户名/你的仓库名/upload/main）

第 2 步  把 Finder 里这个文件夹打开：
            /Users/neil/Desktop/ios app/nestlink-oss

        选中里面全部 5 项，一起拖到网页的虚线框里：
            README.md
            LICENSE
            NOTICE.md
            build-libbox.sh
            PacketTunnel/        ← 整个文件夹，里面 3 个 .swift

        注意：拖 drag 进去后再确认左边「Commit changes」即可。
        不要先点进 PacketTunnel 再拖，那样会丢掉目录层级。

第 3 步  Commit message 随便写，例如：  Initial commit: GPL corresponding source
        然后点绿色的 Commit changes 按钮。

第 4 步  回到仓库首页，确认能看到 README.md 的内容和 PacketTunnel 文件夹。

------------------------------------------------------------

第 5 步（重要）把仓库地址告诉我
        形如：https://github.com/你的用户名/你的仓库名

        我要用它做三件事：
          a) 把 LICENSE 里的「⟨仓库地址待填⟩」替换成真实地址
          b) 把同样的地址写进 App 内的「开源许可」页面
          c) 写进 App Store 审核备注
        这三处不填，披露就是空的，等于白做。

------------------------------------------------------------

如果第 2 步拖拽不成功，改用命令行（需你已配好 SSH 或 token）：

    cd "/Users/neil/Desktop/ios app/nestlink-oss"
    git init -b main
    git add -A
    git commit -m "GPL corresponding source"
    git remote add origin git@github.com:你的用户名/你的仓库名.git
    git push -u origin main
